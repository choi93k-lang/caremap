# 🗺️ 울산 시니어 케어맵 (Ulsan Senior CareMap)

> **공공데이터 기반 고령인구 생활안전 및 의료·여가복지 접근성 대시보드**  
> 핵심 질문: *"울산의 고령인구 분포와 의료·복지 인프라 분포는 지역별로 어떤 차이를 보이는가?"*

---

## 📌 1. 프로젝트 소개
울산광역시 5개 구·군(중구, 남구, 동구, 북구, 울주군) 및 57개 읍·면·동의 고령화율과 의료(병·의원) 및 여가 복지(경로당) 시설 위치를 결합하여 지역 간 인프라 격차를 직관적으로 탐색할 수 있도록 구축된 대시보드입니다.

- **파이썬 초보자 맞춤형 구조**: 복잡한 공간 연산이나 실시간 외부 API 호출 대신, SQLite 로컬 데이터베이스를 통한 단순하고 안정적인 아키텍처
- **객관적 지표 중심**: 주관적인 취약도 점수 대신 공공데이터 원천 수치와 **고령인구 1,000명당 시설 수** 비율 지표 사용
- **Folium 인터랙티브 지도**: 행정동별 고령화율 단계구분도(Choropleth)와 시설별 마커 클러스터링 및 토글 기능 제공

---

## 🚀 2. 실행 방법

본 프로젝트는 초고속 패키지 관리자인 `uv`를 기본 지원합니다.

### 1) 패키지 동기화 및 가상환경 설정
```bash
uv sync
```

### 2) 데이터베이스 초기화 및 데이터 적재 (필요 시)
```bash
uv run python scripts/run_etl_ulsan.py
```

### 3) Streamlit 대시보드 실행
```bash
uv run streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 접속하여 확인합니다.
